# LoanPredict AI

AI-Powered Loan Approval Prediction System built using Machine Learning and Flask.

---

## Overview

LoanPredict AI is a web-based machine learning application that predicts whether a loan application is likely to be approved or rejected based on applicant information.

The system uses a trained Logistic Regression model and provides instant predictions along with approval probability.

---

## Features

- Loan Approval Prediction
- Approval Probability Score
- Modern Dark-Themed Dashboard

## Dataset Information

Dataset contains loan application records with applicant financial and personal information.

### Features Used

- Gender
- Married
- Dependents
- Education
- Self Employed
- Applicant Income
- Coapplicant Income
- Loan Amount
- Loan Amount Term
- Credit History
- Property Area

### Target Variable

- Loan Status
    - Approved (Y)
    - Rejected (N)
